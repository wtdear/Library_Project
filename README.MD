# Library Managment 😊

Небольшое desktop-приложение для ведения учета книг в библиотеке. Разработано на **C#** и **WPF** с использованием **.NET 9.0**. Данные хранятся в виде JSON-файла - не требуется установка и настройка баз данных.

## 📖 О проекте

Приложение позволяет:
- Добавлять, редактировать и удалять книги
- Просматривать список всех книг в табличном виде
- Автоматически сохранять данные в JSON-файл

**Технологии:**
- C# / .NET 9.0
- WPF (Windows Presentation Foundation)
- Хранение данных: JSON-файл

## 🚀 Установка и запуск

### 1. Проверьте версию .NET

Убедитесь, что у вас установлен .NET 9.0 или новее. Откройте терминал (командную строку) и выполните:

```bash
dotnet --version
git clone https://github.com/wtdear/Library_Project
cd library-app
```

### 2. Скачайте репозиторий

```bash
git clone https://github.com/wtdear/library-app.git
cd library-app
```

### 3. Запустите приложение

```bash
dotnet run
```
